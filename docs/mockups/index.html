The frame is the light source

Page is true black. Nothing else on screen is allowed to be brighter or more saturated than the video. Panels sit at #1B1B1B and stay there.

One accent, and it is text-safe

Butter yellow at 18.4:1 on black passes AAA as body text — so unlike the old vermilion it can name the host, mark a live room, and fill a button without a second colour.

Live is yellow, not red

No red anywhere. The live dot, the host ring and the sync readout all use the one accent, pulsing like a filament. A second signal colour would break the rule above.

Soft shells, hard content

Pills for actions, 16px cards, 20px on the video frame. Roundness lives in the chrome; the film keeps clean corners against black.

Elevation by lightness only

black → coal → card → card-2. No shadow, no backdrop-blur, no glowing borders. Hairlines are decorative and never carry meaning alone.

Show, don't list

The landing hero is a real room running — frame, faces, chat, reactions. No numbered steps, no feature cards, no icon tiles.
